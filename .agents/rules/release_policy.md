# Release Versioning & Git Push Policy

## Version Naming Conventions
- `vX.X.0`: Use exclusively for **final release files**.
- `vX.X.X`: Use exclusively for **small updates or bug fixes** (e.g. `v1.2.1`).
- Only add or package releases when the user explicitly instructs to do so.

## Git Remote / Push Policy
- **CRITICAL:** Do NOT push anything to GitHub (`git push`, publishing release tags, etc.) without explicit user permission.
